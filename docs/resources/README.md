# 📚 Directorio de Recursos Técnicos Curados

Cada recurso incluye una ficha técnica estandarizada para que sepas con exactitud si es adecuado para tu nivel actual.

## 📖 1. Documentación Oficial Imprescindible

### [MDN Web Docs (Mozilla Developer Network)](https://developer.mozilla.org/)
* **Para qué sirve**: La referencia canónica, más actualizada y confiable sobre HTML, CSS, JavaScript y Web APIs.
* **Nivel recomendado**: Principiante a Avanzado.
* **Qué aprenderás**: Sintaxis estándar, compatibilidad entre navegadores, ejemplos interactivos y accesibilidad.
* **Formato y Coste**: Documentación abierta / 100% Gratuito.

### [Python Official Documentation & Tutorial](https://docs.python.org/3/tutorial/)
* **Para qué sirve**: La guía oficial escrita por los creadores de Python.
* **Nivel recomendado**: Principiante a Intermedio.
* **Qué aprenderás**: Estructuras de datos nativas, control de flujo, módulos, clases y la biblioteca estándar.
* **Formato y Coste**: Documentación oficial / 100% Gratuito.

### [PostgreSQL Official Documentation](https://www.postgresql.org/docs/)
* **Para qué sirve**: El manual definitivo del motor de bases de datos relacional más avanzado del mundo.
* **Nivel recomendado**: Intermedio a Avanzado.
* **Qué aprenderás**: SQL profesional, tipos de datos avanzados, índices B-Tree, optimización y transacciones ACID.
* **Formato y Coste**: Documentación oficial / 100% Gratuito.

## 🎓 2. Cursos Fundacionales de Referencia

### [CS50x: Introduction to Computer Science (Harvard University)](https://cs50.harvard.edu/x/)
* **Para qué sirve**: Considerado mundialmente como el mejor curso introductorio a las ciencias de la computación.
* **Nivel recomendado**: Principiante absoluto (con alta exigencia académica).
* **Qué aprenderás**: Pensamiento computacional, algoritmos, memoria y punteros en C, estructuras de datos, Python, SQL y desarrollo web.
* **Formato y Coste**: Plataforma edX / Gratuito (auditoría libre de tareas y clases).

### [Full Stack Open (Universidad de Helsinki)](https://fullstackopen.com/)
* **Para qué sirve**: Formación integral en desarrollo web moderno impartida por la prestigiosa Universidad de Helsinki.
* **Nivel recomendado**: Intermedio (requiere nociones básicas de programación).
* **Qué aprenderás**: React, Node.js, Express, bases de datos relacionales y no relacionales, TypeScript, Docker y CI/CD.
* **Formato y Coste**: Curso abierto interactivo / 100% Gratuito.

### [Machine Learning Specialization - Andrew Ng (Coursera / DeepLearning.AI)](https://www.coursera.org/specializations/machine-learning-introduction)
* **Para qué sirve**: El estándar de oro mundial para aprender Machine Learning desde los fundamentos matemáticos hasta redes neuronales y algoritmos supervisados/no supervisados.
* **Nivel recomendado**: Principiante a Intermedio.
* **Qué aprenderás**: Regresión lineal/logística, descenso del gradiente, árboles de decisión, XGBoost, PCA, K-Means y sistemas de recomendación.
* **Formato y Coste**: Coursera / Freemium (auditoría gratuita; opción de pago para certificado).

### [Data Engineering Zoomcamp (DataTalks.Club)](https://github.com/DataTalksClub/data-engineering-zoomcamp)
* **Para qué sirve**: El mejor programa abierto y práctico del mundo para dominar Ingeniería de Datos moderna.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Docker, PostgreSQL, Terraform, GCP, pipelines batch con Spark, orquestación con Airflow/Mage, transformaciones con dbt y streaming con Kafka.
* **Formato y Coste**: Repositorio y videos abiertos / 100% Gratuito.

## 📺 3. Canales de YouTube de Alto Valor Técnico

### [ByteByteGo (Alex Xu)](https://www.youtube.com/@ByteByteGo)
* **Para qué sirve**: Animaciones y explicaciones visuales de System Design, arquitectura distribuida y escalabilidad.
* **Nivel recomendado**: Intermedio a Avanzado.
* **Qué aprenderás**: Cómo funcionan internamente sistemas como YouTube, Discord o Redis, balanceo de carga y colas.
* **Formato y Coste**: Videos semanales de 10-15 minutos / Gratuito.

### [StatQuest with Josh Starmer](https://www.youtube.com/@statquest)
* **Para qué sirve**: La explicación visual más amigable, didáctica y rigurosa sobre estadística, Machine Learning y Deep Learning del planeta.
* **Nivel recomendado**: Principiante a Avanzado.
* **Qué aprenderás**: Árboles de decisión, Random Forest, redes neuronales, transformers y valores $p$.
* **Formato y Coste**: Videos educativos paso a paso / 100% Gratuito.

### [Seattle Data Guy (Ben Rogojan)](https://www.youtube.com/@SeattleDataGuy)
* **Para qué sirve**: Orientación profesional, diseño de pipelines y comparativas de herramientas de Ingeniería de Datos modernas.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Snowflake vs Databricks, modelado Kimball, dbt, Airflow y entrevistas de Data Engineering.
* **Formato y Coste**: Videos de análisis y tutoriales / Gratuito.

### [Fireship](https://www.youtube.com/@Fireship)
* **Para qué sirve**: Resúmenes ultrarrápidos y pragmáticos ("en 100 segundos") sobre nuevas tecnologías, herramientas e ingenierías.
* **Nivel recomendado**: Todos los niveles.
* **Qué aprenderás**: Panorama general de herramientas, arquitectura y cultura técnica sin rodeos.
* **Formato y Coste**: Videos cortos / Gratuito.

### [mouredev by Brais Moure](https://www.youtube.com/@mouredev)
* **Para qué sirve**: Cursos completos en español, retos de programación y divulgación de desarrollo de software y comunidad.
* **Nivel recomendado**: Principiante a Intermedio.
* **Qué aprenderás**: Lenguajes desde cero (Python, JS, Swift, Kotlin), buenas prácticas y rutas de aprendizaje.
* **Formato y Coste**: Videos y transmisiones en vivo / Gratuito.

## 📚 4. Libros Clásicos Imprescindibles

### *"A Tour of C++"* / *"The C Programming Language"* (Kernighan & Ritchie)
* **Para qué sirve**: Entender la relación directa entre el código y la memoria del procesador.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Punteros, gestión manual de memoria, structs y llamadas al sistema operativo.

### *"Designing Data-Intensive Applications"* (Martin Kleppmann)
* **Para qué sirve**: La biblia contemporánea de los sistemas distribuidos y la persistencia a gran escala.
* **Nivel recomendado**: Avanzado.
* **Qué aprenderás**: Modelos de almacenamiento, replicación, particionamiento, transacciones y consistencia distribuida.

### *"Fundamentals of Data Engineering"* (Joe Reis & Matt Housley - O'Reilly)
* **Para qué sirve**: El estándar de facto contemporáneo para comprender el ciclo de vida de los datos, desde la generación hasta el consumo analítico.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Almacenamiento, ingesta, transformación, orquestación, calidad de datos y gobernanza.

### *"An Introduction to Statistical Learning (ISLR)"* (Gareth James et al.)
* **Para qué sirve**: La guía fundamental y rigurosa de algoritmos de Machine Learning y estadística aplicada.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Regresión, clasificación, remuestreo, regularización y aprendizaje no supervisado.
* **Formato y Coste**: Libro / [PDF Oficial Gratuito](https://www.statlearning.com/).

### *"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow"* (Aurélien Géron)
* **Para qué sirve**: La guía más práctica y completa de código para implementar pipelines de Machine Learning y Deep Learning.
* **Nivel recomendado**: Intermedio a Avanzado.
* **Qué aprenderás**: Redes neuronales, algoritmos ensemble, transformers y puesta en producción.

### *"Refactoring: Improving the Design of Existing Code"* (Martin Fowler)
* **Para qué sirve**: Aprender a transformar código desordenado y difícil de mantener en código modular y limpio paso a paso.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Catálogo de malos olores de código (*Code Smells*) y técnicas seguras de refactorización con pruebas.

## 💻 5. Plataformas Interactivas de Práctica y Retos

### [LeetCode](https://leetcode.com/)
* **Para qué sirve**: El estándar de la industria para practicar algoritmos y estructuras de datos para entrevistas técnicas.
* **Nivel recomendado**: Intermedio.
* **Qué aprenderás**: Patrones algorítmicos, optimización de tiempo/memoria Big-O y resolución metódica de problemas.
* **Formato y Coste**: Plataforma web / Freemium (gran banco de problemas gratuitos).

### [Exercism](https://exercism.org/)
* **Para qué sirve**: Práctica de programación con retroalimentación humana de mentores voluntarios en más de 60 lenguajes.
* **Nivel recomendado**: Principiante a Intermedio.
* **Qué aprenderás**: Idiomatic code (escribir código con las mejores prácticas propias de cada lenguaje).
* **Formato y Coste**: Plataforma abierta / 100% Gratuito y sin fines de lucro.

### [Codewars](https://www.codewars.com/)
* **Para qué sirve**: Retos interactivos de programación tipo kata por niveles (de 8 kyu a 1 kyu) creados por la comunidad.
* **Nivel recomendado**: Principiante a Avanzado.
* **Qué aprenderás**: Fluidez sintáctica, trucos del lenguaje y resolución de algoritmos compactos.
* **Formato y Coste**: Plataforma web / 100% Gratuito.
