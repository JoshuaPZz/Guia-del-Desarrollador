## 🎯 ¿Para Quién es Este Repositorio?

Este recurso fue diseñado desde cero para responder de forma constante y honesta a una sola pregunta:

> **"¿Qué debería aprender ahora, por qué debería aprenderlo, en qué orden y dónde puedo practicarlo?"**

Es especialmente útil para:
* 🐣 **Personas que empiezan desde cero absoluto**: Sin formación técnica previa, que necesitan un mapa claro sin jerga incomprensible.
* 🎓 **Estudiantes universitarios o de institutos**: Que buscan conectar la teoría académica con los estándares reales exigidos por las empresas.
* 🔄 **Personas en transición de carrera**: Profesionales de otras áreas que quieren aprender a programar de forma eficiente sin perder meses en tutoriales inservibles.
* 💻 **Desarrolladores Junior**: Que ya saben escribir código en un lenguaje o framework pero tienen lagunas en Git, bases de datos, redes, testing o arquitectura.
* 🔀 **Desarrolladores en cambio de especialización**: Programadores experimentados que quieren pivotar hacia Cloud, Backend, DevOps o Inteligencia Artificial.

                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│          3. ENTORNO PROFESIONAL: GIT & TERMINAL        │ -> Linux básico, Git branches, Conventional Commits
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│      4. REDES, PROTOCOLOS WEB & BASES DE DATOS         │ -> HTTP/HTTPS, REST, JSON, SQL, PostgreSQL, ACID
└───────────────────────────┬────────────────────────────┘
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼

## 🧭 Especializaciones: Elige tu Camino

**No intentes aprender todas las especializaciones**. Escoge una según tus afinidades y profundiza en ella:

### 1. Frontend Developer
* **En qué te enfocas**: La experiencia de usuario, interfaces visuales, accesibilidad y rendimiento en el navegador.
* **Stack nuclear**: HTML5, CSS3 moderno (Flexbox/Grid), JavaScript (ES6+), TypeScript, React o Vue, Tailwind CSS / Vanilla CSS, Vitest.
* **Guía detallada**: [docs/frontend/README.md](docs/frontend/README.md)

### 2. Backend Developer
* **En qué te enfocas**: Lógica de negocio, APIs, integridad de datos, autenticación, seguridad y rendimiento del servidor.
* **Stack nuclear**: TypeScript (Node.js/Express/Fastify), Python (FastAPI) o Go; PostgreSQL, Redis, Docker, Git.
* **Guía detallada**: [docs/backend/README.md](docs/backend/README.md)

### 3. Full Stack Developer
* **En qué te enfocas**: Construcción integral de productos web completos de extremo a extremo.
* **Stack nuclear**: TypeScript en todo el stack (Next.js / React + Node.js), PostgreSQL, Docker, GitHub Actions, despliegue en Cloud.
* **Recomendación**: Domina primero el Backend o el Frontend por separado antes de autodenominarte Full Stack.

### 4. Data Engineer (Ingeniería de Datos)
* **En qué te enfocas**: Construcción y escalamiento de pipelines de datos masivos (ETL/ELT), Data Warehouses y Lakehouses.
* **Stack nuclear**: Python, SQL avanzado (Window Functions), Apache Spark, dbt, Apache Airflow, Snowflake / BigQuery, Apache Kafka.
* **Guía detallada**: [docs/data-engineering/README.md](docs/data-engineering/README.md)

### 5. Data Scientist & Machine Learning Engineer
* **En qué te enfocas**: Análisis estadístico exploratorio, modelado predictivo, algoritmos de aprendizaje supervisado/no supervisado y MLOps.
* **Stack nuclear**: Python, Pandas, NumPy, Scikit-Learn, XGBoost, PyTorch, MLflow, FastAPI, Docker.
* **Guía detallada**: [docs/data-science/README.md](docs/data-science/README.md)

### 6. DevOps & Cloud Engineer
* **En qué te enfocas**: Automatización de infraestructura, pipelines de despliegue continuo, observabilidad y confiabilidad de sistemas.
* **Stack nuclear**: Linux, Bash, Docker, Kubernetes, Terraform, GitHub Actions, AWS o Azure, Prometheus/Grafana.
* **Guía detallada**: [docs/devops/README.md](docs/devops/README.md) y [docs/cloud/README.md](docs/cloud/README.md)

### 7. AI & LLM Engineer
* **En qué te enfocas**: Aplicaciones generativas con Modelos de Lenguaje, arquitecturas RAG, bases vectoriales y agentes autónomos.
* **Stack nuclear**: Python/TypeScript, OpenAI/Anthropic/Gemini APIs, Qdrant/pgvector, LangChain/LlamaIndex, Model Context Protocol (MCP).
* **Guía detallada**: [docs/artificial-intelligence/README.md](docs/artificial-intelligence/README.md) y [docs/ai-for-developers/README.md](docs/ai-for-developers/README.md)

### 8. Ciberseguridad (AppSec)
* **En qué te enfocas**: Detección y mitigación de vulnerabilidades, auditoría de código, seguridad de redes y criptografía.
* **Stack nuclear**: Redes TCP/IP, Linux, Python/Bash, herramientas de análisis estático (SAST), estándares OWASP.
* **Guía detallada**: [docs/security/README.md](docs/security/README.md)

## 💡 Cómo Utilizar esta Guía sin Abrumarse

1. **Acepta que el software es vasto**: Nadie en la industria conoce absolutamente todas las tecnologías. Lo que distingue a los grandes ingenieros es su **capacidad de aprender con autonomía y comprender los principios subyacentes**.
2. **Aplica la Regla 1:2**: Por cada hora que pases leyendo teoría o documentación, pasa 2 horas escribiendo código en tu computadora sin mirar soluciones.
3. **Construye proyectos incrementales**: Dirígete a la sección de [Proyectos](docs/projects/README.md) e implementa el proyecto correspondiente a la fase en la que te encuentras.
4. **Consulta la documentación oficial**: Haz de los enlaces oficiales tu primer puerto de llegada cuando una duda técnica aparezca.
